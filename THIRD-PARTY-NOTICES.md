# Third-party notices

## FLTK

The SVG label-symbol previews in `index.html` adapt drawing geometry from [FLTK 1.3 `fl_symbols.cxx`](https://github.com/fltk/fltk/blob/branch-1.3/src/fl_symbols.cxx). The original drawing code is copyright 1998–2010 by Bill Spitzak and others; the upstream file also credits original code by Mark Overmars. This workbench translates the drawing geometry into SVG paths and JavaScript for browser previews; it does not link to the FLTK library. The [upstream FLTK license and exceptions](./FLTK-COPYING) are included for reference.
