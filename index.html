FLTK @ Symbols (Click to append)

Attach modifiers to the symbol without spaces: @-2refresh smaller, @+3refresh larger. @@ displays a literal @.

Order after @: # square proportions; +1..+9 / -1..-9 size; $ horizontal flip / % vertical flip; rotation; then the symbol name.

Rotation follows the numeric keypad: @8-> up, @2-> down, @4-> left; 5/6 leave it unchanged. Use 0 plus four digits for an angle, e.g. @00090->. @+92-> is a large downward arrow.

Keep symbols at the beginning/end of the label. SVG previews follow FLTK symbol geometry; sizing, shading and antialiasing can differ from fldigi. FLTK reference
